# Pikmin 3 MSBF Tool
This is a tool for editing the LMS binary flowchart files inside Pikmin 3 & Pikmin 3 Deluxe.
## Usage
Run the program with python 3.10+, no extra dependancies should need to be installed.
## Note:
As of right the tool is missing most labels for branch and event functions, this is because they have yet to be reverse engineered and understood. The tool also only supports editing node paramater data, ability to edit the rest of the node data, and to add new nodes branches and flowcharts will be added in the future.
